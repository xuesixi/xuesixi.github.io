# Personal Resume Website

A professional, responsive resume website for Computer Science students looking for jobs.

## 🎯 Features

- **Professional Design**: Clean, modern layout with a gradient header and organized sections
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Easy to Customize**: Simple HTML structure with placeholder content ready to be personalized
- **Print-Friendly**: Optimized styles for printing your resume
- **Fast Loading**: Minimal dependencies, pure HTML and CSS

## 📋 Sections Included

- **Header**: Name, title, and contact information
- **About Me**: Brief introduction and career objectives
- **Education**: Academic background and coursework
- **Technical Skills**: Programming languages, frameworks, and tools organized by category
- **Projects**: Showcase your best work with descriptions and links
- **Experience**: Work experience and internships
- **Leadership & Activities**: Extracurricular involvement
- **Contact**: Call-to-action for potential employers

## 🚀 Quick Start

1. **Edit `index.html`**: Replace placeholder text with your information
   - Update your name, email, phone, and social links
   - Add your education details
   - List your skills, projects, and experience
   
2. **Customize Colors (Optional)**: Edit `styles.css` CSS variables at the top:
   ```css
   :root {
       --primary-color: #2c3e50;
       --secondary-color: #3498db;
       --accent-color: #e74c3c;
   }
   ```

3. **Deploy**: 
   - Push changes to GitHub
   - Enable GitHub Pages in repository settings
   - Your site will be available at `https://yourusername.github.io`

## 💡 Customization Tips

- Keep descriptions concise and achievement-focused
- Use action verbs (Developed, Built, Implemented, etc.)
- Add links to your GitHub projects and live demos
- Update the meta tags in the `<head>` section for better SEO
- Consider adding a profile photo in the header section

## 🌐 View Your Site

Once deployed on GitHub Pages, your resume will be publicly accessible and shareable with potential employers!

## 📱 Responsive Design

The website automatically adapts to different screen sizes:
- **Desktop**: Full layout with side-by-side skills grid
- **Tablet**: Adjusted spacing and font sizes
- **Mobile**: Single-column layout optimized for small screens
